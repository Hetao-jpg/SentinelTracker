  哨兵综合症监控 · SentinelTracker
  作者：核桃 | 最新版本：1.2.0
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

游戏：Probably Stolen 0.46D
环境：MelonLoader 7.4 及以上


▎安装
把 SentinelTracker.dll 放进游戏
目录的 Mods/ 文件夹，启动即可。


▎做什么
按 F3 打开悬浮监控窗口，
实时显示哨兵综合症状态：

  距离上次打针的天数
  损伤池当前值（pool / 20）
  当前所处阶段
  距哨兵崩溃还有几晚
  打针建议（真品 / 过期 / 假货）
  真品免疫宁 -1 损伤池（可选，默认关）

窗口可拖动、可缩放、可调
透明度，全部实时生效。


▎核心机制（与原版代码一致）
哨兵不会“掉血”，唯一后果是：
  每晚按天数往“损伤池”里加点
  池只增不减，打针也不降池
  池 ≥ 20 → 触发“哨兵崩溃”死亡

打针只重置“天数”，不重置池。
开启 ReducePoolOnGenuineInject 后，
真品针每次 -1 池（mod 新增，可选）。


▎五阶段状态（天数 → 涨速）
  安全期（0~5 天）   绿    +0 / 晚
  提示期（6 天）     黄    +0 / 晚（仅弹提示）
  警告期（7~9 天）   橙    +1 / 晚
  重损期（10~13 天） 红    +2 / 晚
  濒死期（14+ 天）   深红  +3 / 晚

面板会同时显示“损伤池进度条”
和“若不注射，预计 N 晚后崩溃”。


▎免疫宁成色
  真品 → 天数归 0
  过期 → 天数变 3
  假货 → 天数随机 3/4/5
  ※ 原版任何针都不降损伤池
  ※ 开启 -1 池开关后，真品每次 -1

▎操作
  F3        开 / 关面板
  拖标题栏   移动窗口位置
  拖右下角   调整窗口大小
  点右上角 × 关闭面板


▎配置项（共 10 项）
【通用】
  显示监控面板（默认开）
  面板开关按键（默认 F3）
  仅哨兵玩家显示（默认关）
  显示免疫宁提示（默认开）
  真品免疫宁 -1 损伤池（默认关）

【透明度】
  面板背景透明度（默认 0.9）
  文字透明度（默认 1.0）
  缩放手柄透明度（默认 0.6）

【窗口尺寸】
  面板宽度（默认 360）
  面板高度（默认 340）

【面板位置】
  不在 cfg 里，玩家拖动即可。
  位置自动保存，跨存档共享。


▎已知限制
· 面板必须在游戏内进图后
  才有数据；主菜单下显示
  “等待进入游戏...”
· 面板位置全局共享，不随存档
  区分（它是 UI，不是游戏内容）
· 免疫宁成色提示是静态速查，
  不读取实际库存
· 死亡倒计时按“今晚睡前”起算
·ReducePoolOnGenuineInject 改动
  需要重启游戏才生效
